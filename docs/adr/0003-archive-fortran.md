# Archive Fortran as historical reference

The live system is the Rust replica (`rust/`) and the Vue console (`web/`). The original Illinois Fortran 77 sources and FDD `d*.dat` files stay in `archive/` so a first look at the repo is the current product, while the published codes remain available for comparison. Leaving them at the root would keep presenting this as a Fortran distribution; dropping them would lose the translation reference.
